Privacy and data

Mirror reads the active tab's address once a minute to sort it into a category (short video, social, news, other), then discards it. In demo mode it does this every 2 seconds. Sites and addresses are never stored. Chrome describes this permission as "Read your browsing history".

Sync is optional. If you connect an account, daily totals are encrypted here before upload, and the policy below allows only our sync server. The server still sees your email, IP address and when you sync. The current two recovery words are for the prototype, not strong protection.

The camera is off unless you turn on posture. Frames are read in memory on this laptop and never saved or sent. Only proportions, the last result and daily estimates are kept.
